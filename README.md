# 🎓 SmartClass 智慧課堂點名與出缺席即時管理系統

這是一個基於純原生 **HTML5 + CSS3 + Modern JavaScript (ES6+)** 開發的現代化智慧課堂點名管理系統。專為教學現場設計，提供直覺、活潑且高效率的點名體驗，具備多種點名模式、即時統計儀表板、互動抽籤機制以及缺席學生通知系統。

---

## 🌟 核心特色與亮點功能

### 1. 📋 多樣化點名模式
- **全班清單點名 (List Mode)**：
  - 網格化排列所有學生卡片，清楚顯示學生姓名、學號、分組、頭像與聯絡資訊。
  - 一鍵切換 **【出席】**、**【請假】**、**【缺席】**，支援再次點擊取消標記。
  - 即時即打即找（姓名、學號、信箱即時搜尋）。
  - 狀態快速篩選 Pill：全部、出席、請假、缺席、未標記。
  - 課堂平時表現加扣分按鈕（`+` / `-`）。
- **🎲 趣味隨機抽點互動 (Lucky Draw Mode)**：
  - 結合指針轉盤與隨機跑馬燈動畫，增加課堂師生互動趣味！
  - 內建智慧過濾開關：
    - 可勾選 **自動排除已缺席/請假學生**。
    - 可勾選 **避免本堂重複抽出已抽過學生**。
  - 抽中學生後聚焦大卡片，可直接現場標記出缺席狀態與給予「回答良好 (+1 分)」平時獎勵。
  - 抽點歷程抽籤紀錄抽屜，可隨時回溯與清空。
- **⚡ 沉浸極速唱名模式 (Speed Mode)**：
  - 大字體焦點卡片與當前點名進度條（例：第 5 / 20 位）。
  - **鍵盤快捷鍵支援**：
    - `1` 或 `A`：標記 **出席** 並自動跳下一位。
    - `2` 或 `S`：標記 **請假** 並自動跳下一位。
    - `3` 或 `D`：標記 **缺席** 並自動跳下一位。
    - `Space` / `→`：下一位，`←`：上一位。

---

### 2. 📊 即時數據儀表板 (Live Statistics Dashboard)
- **總人數統計**：隨名單動態更新。
- **實到人數** 與 **出席率 (%)**：
  - 配備動態 SVG 環形進度環與流暢動畫。
  - 自動依出席率呈現評級狀態（出席率極佳 🌟 / 良好 👍 / 偏低 ⚠️）。
- **請假人數** 與 **缺席人數** 警示標籤。

---

### 3. 🚨 缺席學生關懷與通知系統 (Absentee Notification)
- 點名完成後，可隨時點擊數據卡片上的 **「發送缺勤通知」** 按鈕。
- 自動彙整當前所有標記為缺席之學生名單與信箱。
- 內建三種專業訊息情境範本：
  1. **🌱 溫馨關懷提醒**：語氣溫和親切，關心身體狀況並附帶課堂講義補看說明。
  2. **📋 正式課堂缺勤警示**：列明校規規定、出席佔分比重與 48 小時內補假手續。
  3. **📝 課堂隨堂測驗/分組公告**：提醒本日分組重要任務與小組協作成員聯繫。
- 訊息內文支援自動套用課程名稱、當日日期與缺席學生姓名。
- 支援功能：
  - 📋 **一鍵複製完整訊息**：直接貼至 LINE 群組、FB 班群或 Teams。
  - ✉️ **開啟郵件用戶端 (mailto:)**：自動填入主旨、內文，並將全體缺席學生信箱置於 **密件副本 (BCC)** 保護學生隱私。
  - 🚀 **模擬推播發送**：即時回饋推播狀態通知。

---

### 4. 🎨 現代化美觀 UI 與活潑色彩
- **微擬物與毛玻璃質感**：柔和卡片陰影、圓角設計、細緻微互動。
- **動態環境流光**：背景活潑柔和的呼吸漸層浮動光球。
- **Web Audio API 原生音效合成引擎**：
  - 抽籤轉盤嘀嗒音效（Tick）。
  - 得獎抽中琶音歡慶和弦（Chime / Fanfare）。
  - 按鍵微點擊回饋音（Pop）。
  - 支援右上角喇叭圖示一鍵開啟 / 關閉靜音。
- **完全響應式設計 (RWD)**：支援手機、平板、筆電與教室投影大螢幕。

---

### 5. 💾 資料保存與匯出管理
- **LocalStorage 本地快取**：瀏覽器重新整理不會遺失點名與分數進度。
- **名冊備份與 CSV 匯出**：
  - 匯出一鍵下載 UTF-8 含 BOM 的 Excel 相容 CSV 報表。
  - 匯出 JSON 完整資料備份檔。
  - 隨時重置或恢復 20 位預設示範名單。
- **新增學生**：可隨時彈窗輸入姓名、學號、組別與電子信箱。

---

## 🚀 如何使用與開啟

1. 本專案為純前端網頁應用程式，**不需要安裝任何伺服器或 Node.js 環境**。
2. 直接使用任何現代瀏覽器（Google Chrome、Microsoft Edge、Safari、Firefox）**雙擊開啟 `index.html`** 即可立即使用！
3. 若您在 VS Code 中，也可以右鍵點擊 `index.html` 選擇 `Open with Live Server`。
